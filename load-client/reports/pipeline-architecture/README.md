## Required report selection

1. One **default** report produced with `--stations=10 --duration=60`.
2. One **stress** report produced with `--stations=100 --duration=120`.

Each report must come from its own fresh run. Before each run, reset MySQL with `db/init-db.ps1`
and start a new server process so the database and all in-process pipeline state are fresh. Select
only a timestamped JSON file generated by the unchanged load client during that run.

Do not edit, normalize, rename, merge, or otherwise rewrite either client-generated JSON file.
Copying the selected file into this directory is allowed only byte-for-byte. Record the two exact
filenames and their reset/restart provenance in the final evidence update to this README.
